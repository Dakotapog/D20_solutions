## 📋 Descripción

D10 Solutions es una plataforma web integral para la gestión de servicios tecnológicos educativos. Ofrece un sistema completo de administración de servicios, usuarios y contenido, con una interfaz moderna y responsive.

## ✨ Características Principales

- 🏠 **Landing Page Profesional** con hero section y presentación corporativa
- 📦 **Catálogo de 10 Servicios** con filtrado por categorías
- 🔍 **Detalle Dinámico** de cada servicio con información completa
- 🔐 **Sistema de Autenticación** para administradores
- ⚙️ **Panel Administrativo** con CRUD completo de servicios y usuarios
- 🔎 **Búsqueda en Tiempo Real** y filtrado avanzado
- 📊 **Dashboard con Estadísticas** visuales
- 📱 **Diseño Responsive** adaptable a todos los dispositivos
- 🌐 **API REST** completa con Flask
